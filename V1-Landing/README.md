# VÉRTICE Technology · V1-Landing

Landing estática de la marca ficticia VÉRTICE Technology. HTML semántico, CSS con BEM y JavaScript nativo para el menú móvil y la cotización demostrativa.

Abre `index.html` directamente en el navegador. Para repetir las pruebas HTTP, ejecuta en este directorio:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

La navegación funciona sin JavaScript. El formulario queda desactivado sin JavaScript. Al validarlo con JavaScript, borra los valores de ejemplo de la interfaz y confirma que no los envió ni los guardó. No hay servicios externos en ejecución.

Las seis fotografías y la imagen Open Graph proceden del paquete aprobado. Space Grotesk e Inter usan subconjuntos latinos WOFF2 de Google Fonts, integrados en `assets/fonts/webfonts.css` para funcionar también al abrir el HTML como archivo. Las licencias SIL OFL 1.1 están junto a la hoja. Antes de publicar, actualiza `og:image` a una URL absoluta del dominio autorizado y verifica la vista previa social.
